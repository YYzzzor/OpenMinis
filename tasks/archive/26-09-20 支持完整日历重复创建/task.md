## 上下文与决定
最新决定：用户确认“每两周组会”仅是例子，目标不缩减为双周重复；因为 App 仅供个人使用，年度周次是极低频场景，明确同意暂缓修复并不阻塞交付。原全接口能力目标保留为背景，本次验收排除这一项及其组合。
用户从“每两周组会”扩展为全部官方重复创建能力，认可系统原生重复规则路线。
调用链：Agent shell_execute → apple-calendar → CalendarOffload → EventKit。
仅日历事件创建；不扩展提醒事项或后台 Agent 定时任务。
EventKit 仅支持单条 recurrence rule；calendarIdentifier/firstDayOfTheWeek 只读，不提供伪造 setter。
校验 Apple 明确不支持/会忽略的频率与字段组合。日期截止包含当天，次数包含首次。
Agent 从 apple-calendar --help 获取参数，create/list 返回规则详情以便核实。
官方依据：https://developer.apple.com/documentation/eventkit/creating-a-recurring-event
SDK 依据：Xcode.app iPhoneSimulator.sdk EventKit.framework/Headers/EKRecurrenceRule.h、EKRecurrenceDayOfWeek.h、EKRecurrenceEnd.h。
