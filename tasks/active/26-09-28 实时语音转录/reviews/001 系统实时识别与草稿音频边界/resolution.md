# 主 Agent 核对与处理

Pi：DeepSeek / deepseek-flash / Pi 0.85.1；快照 877219a1e64894bc2796d20218161bcb914e232540b8da8867f61f1b31fa2f0a；结论 nonblocking，7项意见。原始报告不修改。

| 意见 | 判断与处理 | 验证 / 边界 |
| --- | --- | --- |
| R1 轮换4秒超时 | 保留有界超时策略，尚不接受长句体验验收。超时确实结束录音且显式保留未确认文本；报告所称在线容易超过4秒没有实测证据。不能无依据增大等待或改为无界缓存。 | 需真实长录音测轮换延迟；本轮用户明确仅完成代码和自动验证。 |
| R2 自然终稿时间窗 | 已知限制保持开放。不能把10秒停顿直接等同于10秒后系统才自然终稿，但如果晚到且边界超窗，代码确实会停止。 | 现有超窗单测确认失败路径；代表停顿场景待真实声音验证，必要时提交新API路线。 |
| R3 空识别结果缺反馈 | 采纳并修复。终态前检查本轮实际新增识别文字，无文字则 report(.noSpeechRecognized)，原稿保留，不把原稿误算为识别成功。报告对空草稿的旧文案描述不精确：空草稿原来落回“点麦克风开始说话”；缺乏无语音提示这一问题成立。 | 新增 testEmptyRealtimeResultReportsNoSpeechAndPreservesOriginalDraft。 |
| R4 工具栏与停止键 | 不采纳恢复旧工具栏。交接明确保留当前已认可UI，旧UI任务明确语音模式不显示附件、斜杠、上下文按钮，朗读开关在设置中。当前停止键黑色方块图标，未由本任务改变。 | 当前原生界面截图核对面板/设置；旧任务仍active。不会因与HEAD不同就撤销此前已认可改动。 |
| R5 旧语音入口残留 | 不在本任务清理无调用者的旧入口。新路径未调用旧引擎，不复用按长度追加；当前没有该旧入口导致双录音或改写新草稿的触发证据。hasUnconfirmedTranscript虽无直接视图读取，但 .failed 同时设置 transcribeError / lastFailure，InlineVoiceInputView实际显示失败与保留尾句的说明。 | 已核对新入口与全仓旧引擎引用；保留未来接回旧入口的维护风险。 |
| R6 音频回调锁与分配 | 静态事实成立，运行性能未验证。缓存有上限且回调没有网络等待或每帧异步任务，但同步锁争用/内存复制是否影响实际音频必须测量。未声称无锁或满足任何实时耗时预算。 | 本轮不以静音PCM单测替代Instruments与真实设备证据；风险保持开放，不能称实时性能验收通过。 |
| R7 不足一帧的尾部 | 采纳并修复。ceil 后 offset>=frameLength 时 continue，仅跳过不存在的采样；真正的PCM复制失败仍明确失败，不静默吞音频。 | 新增 testSubsampleTailDoesNotEndRecording 覆盖 2.0-1e-9 秒边界。 |

主 Agent 已直接检查首轮 Xcode 原始日志及结果包位置，15项自动测试成功；Pi未亲自运行测试是独立审查的证据边界，并不否定主 Agent持有的实际测试结果。两项修复后重新构建/测试并安排局部复审，不能沿用首轮快照宣称最终代码已经审查。

最终产品验收保持未完成：真人连续说话、首字延迟、长停顿、请求边界完整性、离线/香港中文/英文能力、真机与实际发送均未验证。任务保持active，不归档。
