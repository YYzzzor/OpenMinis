8. 核对模型结果没有混入完整诊断或敏感凭据。

| 输出情况 | 通过条件 |

| 长正文必须缩短 | 先限制片段再编码，JSON 及来源仍完整。 |

## 统一截止时间与停止矩阵

规则：R1–R4、A1。
被测构建需要提供总时间配置和阶段诊断。
测试适配器需要能够暂停阶段及释放迟到回调。
诊断只记录阶段、状态和调用归属，不包含凭据或完整私人正文。

### 总截止时间

总预算记为 D，具体数值从被测构建或显式测试配置取得。

1. 记录 D 和调用进入队列的时刻。
2. 控制排队、HTTP、备用请求、渲染及提取的耗时。
3. 使各阶段低于各自限制，但累计耗时超过 D。
4. 记录每个阶段的开始、结束、清理和最终状态。
5. 核对路线切换未重置总截止时间。
6. 核对过期后没有进入下一阶段。
7. 核对实际请求和临时渲染已经停止。

已有部分内容需要说明已提交范围和未完成状态。

### 各阶段停止

每个阶段独立执行一轮。
测试人员等待目标阶段已经进入，再触发用户 Stop。

| 停止位置 | 通过条件 |
| --- | --- |
| 等待槽位 | 队列项移除；槽位释放后也不启动该调用。 |
| 主文档或重定向 | 数据任务取消；备用和渲染不启动。 |
| 公开备用来源 | 备用请求取消；已提交内容保留，调用保持中断。 |
| 内部渲染 | 加载、观察和就绪等待结束；既有标签和登录保留。 |
| 提取或正文写入 | 可取消解析停止；未提交正文不能生成可用编号。 |
| 当前并发批次 | 当前批次按规定范围停止；其他聊天继续。 |

触发 Stop 后继续执行以下步骤：

1. 释放迟到网络或 WebKit 回调。
2. 检查调用只结束一次，取消状态保持。
3. 检查回调没有新增消息、缓存或回退。
4. 发起正常后续读取，确认槽位可再次使用。

### 会话删除及异常

对上述各阶段另外执行会话删除和异常注入。

| 动作 | 通过条件 |
| --- | --- |
| 删除当前会话 | 旧正文编号失效，迟到内容不能恢复会话或写入数据库。 |
| 注入阶段异常 | 结果保留原因；请求和槽位释放，后续调用可以继续。 |

两种动作都检查部分文件和未提交正文已经清理。
结束范围内的请求、等待、观察器、队列及临时渲染计数需要归零。
界面消息消失不能单独证明释放。
其他聊天保持独立。

### 锁屏后恢复

1. 使用上一节的相同后台配置执行前台与锁屏对照。
2. 记录 App 和 WebContent 阶段事件、截止时间及实际释放时刻。
3. 恢复后若预算已过期，检查应用立即清理。
4. 记录请求、观察器、队列及临时渲染计数。
5. 在测试配置中注明允许的清理时间容差。

系统暂停期间的界面时间不能证明后台工作成功。

## 同网址、正文编号与身份作用域

规则：I1–I3、C4、R3。
所有作用域测试使用同一个绝对网址 `/long/html`。
改变网址可能掩盖仅按 URL 保存全局缓存的错误。

| 情况 | 测试动作 | 预期结果 |
| --- | --- | --- |
| 聊天 A、当前请求 A1 | 取得编号后继续读取目标段落。 | 返回同一固定正文，不重新下载。 |
| 聊天 B | 使用 A1 的编号，再发起 B 的正常读取。 | A1 编号被拒绝，B 编号属于 B。 |
| A 的后续请求 A2 | 使用 A1 的编号，再发起 A2 正常读取。 | 旧编号失效，新编号属于 A2。 |
| 测试服务改变身份 revision | 使用旧编号并释放旧身份迟到结果。 | 编号失效，旧内容不能进入新身份缓存。 |

身份 revision 测试不授予产品登录读取能力。
每项保存编号作用域、请求次数和缓存诊断。

匿名隔离按以下步骤验证：

1. 仅在既有浏览器通过 `/auth/grant` 建立模拟登录。
2. 确认浏览器可以读取 `/auth/private`。
3. 分别通过匿名 HTTP 和匿名 WebKit 读取同一受保护网址。
4. 核对两条匿名路线都没有私人标记。
5. 核对请求和存储没有复制共享 Cookie 或 Authorization。
6. 核对既有浏览器仍然登录，受保护 Cookie 备份保持原行为。
7. 检查新读取服务的缓存、普通日志及诊断没有私人标记。

审计范围是新读取服务，不清除既有浏览器的合法登录存储。

## 长文、未命中与未覆盖

规则：C2–C4、F2、R2–R3。
测试输入的正文超过30,000字符，目标位于15,000字符之后。

1. 用跨 HTML 标签的代码标识符定位目标。
2. 核对工具重建标识符，并保留代码边界、上下文及表格行列。
3. 分别记录已取得正文、工具格式化结果及最终模型输入的长度。
4. 核对目标片段已送入模型，或可通过正文编号取得。
5. 核对通用截断及文件转存没有丢失来源、定位和未覆盖说明。

| 输入情况 | 测试动作 | 预期结果 |
| --- | --- | --- |
| 完整固定正文 | 查找确定不存在的标识符。 | 报告“已覆盖范围内未命中”。 |
| 同一长文被响应上限截断 | 查找真实尾部标识符。 | 报告目标范围尚未取得。 |
| 静态段落可读、动态目标未出现 | 明确请求渲染。 | 取得动态段落，或说明剩余限制。 |
| 补充期间取消 | 释放迟到回调。 | 不再补充或提交内容。 |

工具只承诺继续读取实际保存的范围。
未命中不能推导整个网站不存在目标。

## 当前文档与旧 DOM

规则：C1、F2、R4。
DOM 是 WebKit 当前保存的网页结构。
文档代次用于区分每次导航，即使两次网址相同。

1. 在内部渲染器加载带旧标记的文档 A。
2. 请求带新标记的文档 B，并延迟 B 的主响应。
3. 核对正文就绪检查绑定本次文档代次及目标网址。
4. 另外测试同网址重新加载的文档代次。
5. 让 B 正文先于装饰资源就绪，核对工具返回 B。
6. 核对旧标记没有进入结果或正文缓存。
7. 核对 B 提取后结束无用加载及观察。

| 导航结果 | 预期结果 |
| --- | --- |
| B 尚未取得 | 工具等待到预算结束，或说明部分状态。 |
| B 导航失败 | 工具报告失败，不将 A 正文作为 B 返回。 |
| 重定向成功 | 工具报告实际新来源。 |

## 完整 Agent 查询

规则：W3、A1–A3。
测试使用正常生产系统提示、全部工具和同一模型配置。

代表查询使用分组清单中的5类模板：

| 模板 | 查询目的 |
| --- | --- |
| Q01 | 读取已知公开官方说明，并复用已有充分证据。 |
| Q02 | 定位长文代码或表格，并补充局部动态目标。 |
| Q03 | 通过搜索操作发现来源，再读取公开正文。 |
| Q04 | 读取已授权浏览器的登录或交互后页面。 |
| Q05 | 查询图片中的价格，验证资源交接和事实对应。 |

Q02 的长文和动态输入分别执行，关键输入不能合并为一次观察。
Q04 的登录和交互状态分别执行，使用合成身份。
Q05 通过现有图像工具读取，不为 `web_read` 新增 OCR。
5类模板允许参数化，不限制为5次调用或5条轨迹。
每类使用相同配置重复，并记录实际样本数。
G20 另行检查真实混合批次及重载后的正常查询。

| 记录类别 | 保存内容 |
| --- | --- |
| 回答 | 最终回答、事实对应来源及缺失项。 |
| 工具 | 实际选择、完整模型可见结果及调用次数。 |
| 时间 | 下载、提取、备用、渲染、工具总时间及完整查询时间。 |
| 模型 | 模型配置及请求次数。 |
| 输出与失败 | 输出规模、协议失败及未完成原因。 |
| 资源 | App 和 WebContent 的实际观察。 |

先判断正确性、隔离、取消和资源边界，再比较速度。
多次查询报告实际样本数和耗时分布。
失败查询或仅下载时间不能作为完整查询提速依据。

PDF 或图片未读取时，边界识别可以通过，内容查询仍未完成。
图像交接成功后，继续核对数字与具体图片的对应关系。
Responses 多图片配对错误作为独立依赖记录。

## 工具选择与证据复用

规则：W4–W6、I1–I3、A1、A2、A4。
本节对应三个案例：

- `coexist-public-tool-routing`。
- `coexist-existing-evidence-no-refetch`。
- `coexist-authenticated-browser-routing`。

### 公开读取和搜索操作

1. 使用正常提示，多次提出已知公开网址读取请求。
2. 另外提出需要搜索页面操作的请求。
3. 记录真实工具选择及内部请求。
4. 核对公开读取优先选择 `web_read`。
5. 核对搜索页面操作选择 `browser_use`。
6. 核对内部 HTTP、备用正文及渲染属于同一次读取调用。

强制指定工具的提示不能证明模型会自行选择工具。

### 已有证据

1. 分别准备目标已覆盖和目标有明确缺口的查询。
2. 在各自同一用户请求中记录首次内容取得后的调用增量。
3. 核对已有充分证据直接用于回答。
4. 核对新增读取对应缺口、时效更新或刷新要求。
5. 核对匿名缓存只保存匿名工具自身取得的正文。

追加用户消息会开始新请求，不能冒充同一请求内的证据复用。
浏览器合法返回的内容可以保留在当前模型上下文。

### 登录和交互状态

1. 在独立准备步骤中访问 `/auth/grant`，建立浏览器模拟登录。
2. 确认 `/auth/private` 可读，不将正文提前送入本次模型上下文。
3. 分别通过匿名 HTTP 和 WebKit 读取同一网址。
4. 核对匿名结果说明限制，且没有私人标记。
5. 使用正常提示请求需要已授权身份的页面内容。
6. 核对模型选择 `browser_use` 并读取对应标签。
7. 另外使用用户交互后的受控页面，核对读取继续针对该标签。
8. 核对来源和身份范围，以及既有登录仍然可用。

提前注入私人正文可能使模型直接回答，掩盖工具选择。
原许可及确认语义保持，实验只使用合成身份。

## 并行状态与接管

规则：I2、I4、R6、A4。
对应 `coexist-tab-state-and-takeover`。

| 记录对象 | 保存内容 |
| --- | --- |
| 标签和页面 | `tab_id`、URL、DOM 标记。 |
| 用户操作 | 输入值和滚动位置。 |
| 配置 | UA、viewport 和登录状态。 |
| 接管 | 暂停、等待及恢复事件。 |

1. 先使匿名 HTTP 或渲染进入执行。
2. 再由用户操作或接管既有标签。
3. 另外测试其他聊天的读取与接管并行。
4. 分别控制读取正常完成、取消和超时。
5. 核对读取只导航自身实例，并返回自身目标文档。
6. 核对读取没有修改既有标签或提前解除接管。
7. 由用户结束接管，确认原会话正常恢复。

已暂停的同会话不再新发工具批次。
页面自身异步变化与读取造成的修改分别判断。
单纯比较截图像素不足以判断状态隔离。
读取清理不能停止、重建或清除既有浏览器。

## 共同资源预算

规则：R1、R3、R5、I4、A4。
对应 `coexist-global-render-capacity`。

| 配置 | 含义 |
| --- | --- |
| G | 浏览器和匿名 WebKit 的共同实例上限。 |
| Q | 等待请求上限。 |
| D | 从进入队列开始计算的总时间预算。 |

测试从被测构建或显式配置取得 G、Q、D。
测试网站的8线程上限与产品 G 分别记录。

1. 记录每个实例的创建、销毁、所属聊天和调用。
2. 先用活动或接管的浏览器占据部分 G，再请求超额匿名渲染。
3. 将浏览器占用增加到全部 G，重复读取请求。
4. 反向先启动读取，再创建浏览器标签。
5. 核对两个顺序的总占用均不超过 G，队列不超过 Q。
6. 核对排队计入 D，读取准入不抢占活动或接管标签。
7. 注入资源压力，检查可释放读取资源已经清理。
8. 逐个释放持有者，确认未过期队列能公平恢复。
9. 释放重复回调，检查没有负计数、重复释放或丢失槽位。

被结束的读取需要说明受限或未完成。
已取消或过期的队列项不能重新启动。
既有浏览器自身的回收行为单独识别。

测试同时记录代表性 App 和 WebContent 内存及耗时。
数量上限只能证明准入有界，不能证明内存或能耗改善。
没有测量时保留未验证状态，不引入生产高频轮询。

## 取消范围与结果配对

规则：R1、R2、R6、I4、A1、A4。
本节对应三个案例：

- `coexist-timeout-isolation`。
- `coexist-session-and-batch-stop`。
- `coexist-result-pairing-and-reload`。

### 单次调用

1. 在同聊天启动读取 A、B 和浏览器工作。
2. 在其他聊天启动独立工作。
3. 分别在排队、HTTP、渲染及提取阶段使 A 超时或按调用标识取消。
4. 释放 A 的迟到回调。
5. 核对只有 A 清理，B、浏览器导航及其他聊天继续。
6. 反向触发浏览器超时，核对匿名读取继续。

本项使用内部调用取消，不使用会话或气泡 Stop。

### 批次和会话

| 触发 | 通过条件 |
| --- | --- |
| 工具气泡 Stop | 当前批次的两种工具及队列项都结束。 |
| 只有 `web_read` 活动或排队时点击 Stop | 停止按钮有效，读取实际结束。 |
| 会话 Stop | 当前会话活动请求内的工具、等待及队列结束。 |
| 删除会话 | 任务先停止，数据和编号按原生命周期清理。 |

其他聊天继续，Stop 保留已提交结果及既有登录。
气泡停止沿用批次语义，不能标记为单次调用取消。
迟到内容不能恢复任务或删除的会话。
未来尚未开始的用户消息队列沿用原 Spec 的待决定项。
已经发生的网页副作用按原规则保留。

### 乱序和重新加载

1. 让真实批次同时包含 `web_read` 和 `browser_use`。
2. 使用不同调用标识、来源及目标。
3. 按相反顺序完成调用，并混入超时和取消。
4. 核对界面、Provider history 及数据库中的调用标识和工具名。
5. 核对来源、身份和终态一致。
6. 重新加载会话，再检查配对并继续正常 Agent 查询。

已取消内容不能覆盖其他调用或已结束调用。
内部读取阶段不能伪造额外模型工具调用。
每项保存阶段时刻、取消目标及实际资源释放证据。
