## 功能与设计要求

真实使用目标：阅读或输入消息时直接了解上次请求的上下文占用，同时保持现有输入工具行布局。

- 放在现有底部工具行，紧邻麦克风左侧，和麦克风、发送按钮归右侧一组；不居中，不新增行，不单独增加输入框高度。
- 小静态圆环 + 整数百分比，次要灰色；v10采用A方案等高胶囊，复用其它输入按钮的底色和边线。不新增告警或改变压缩策略。
- 点击打开现有会话 Token 用量详情；详情与指标使用同一份上下文数值，并解释统计口径。
- 复用原工具行的12pt可见背景边界间距；v10改为胶囊右边界到麦克风圆形背景左边界12pt。v11保留用户调整后的胶囊内部左右各1pt留白，取代v10的10pt。
- v9 真机反馈后的默认样式：数字与输入框占位文字共用16.5pt字号，等宽数字；圆环直径19.25pt、线宽2.0625pt，圆环到数字5pt。三者随输入字号设置缩放，取代原14pt圆环/12ptcaption。
- v11按一位、两位、三位数字分档预留宽度；同档内宽度稳定，圆环和实际文字在胶囊内部居中，胶囊仍位于麦克风左侧；整数位数变化不推动麦克风和发送。未知显示空环 + `—`；超过容量可以显示 >100%，圆环最多一圈；极端值缩写为 `999%+`。
- 默认按钮最小高度 34pt，与现有工具行匹配；最小宽度44pt，实际通常更宽。不声称已经获得44×44pt触摸高度。较大字体可自然增高。
- 窄空间下语音朗读/退出编辑辅助按钮可收起文字，仍保留图标操作及无障碍名称；不得遮挡主操作。

## 统计口径与边界

- 显示最近有效 API 请求输入 tokens / 该请求对应的有效上下文窗口。包括缓存输入；不包括未发送草稿、这次生成的回复或后续工具结果。
- 采用 `TokenUsage.latestContextTokens`；不用累计会话消费，不把峰值 input 与最新缓存拼成分子，不用字符估算兜底。
- 首次尚无可靠统计时未知；已建立的统计按Session在本机持久保存，普通切换/重启验证后恢复。清空、编辑/重试截断、压缩/撤销压缩、实际卸载与图片裁剪后失效，等待下一次有效请求。
- 绑定实际 entry/model/provider/有效窗口与本会话相关配置摘要；请求进行中仍用配置修订拒绝迟到结果；切换模型后旧分子不能与新窗口拼接，切回旧模型也不能复活旧统计。
- 配置失效限于该会话的主模型来源、实际模型配置和provider连接设置；其它会话绑定保存不使已有统计丢失。fallback 仅在实际来源、预捕获路由和流阶段修订均可确认时接受；否则不发布本次统计，保留仍匹配当前配置的上次有效值；没有有效旧值时显示未知。
- 普通续聊和同一轮下一次请求开始时保留上次有效快照；新有效usage到达后替换。缺失或无效新usage时保持上次有效值。压缩/截断/重载等实际失效事件才清空；上下文失效后迟到结果不能恢复快照。
- UI getter 不扫描消息历史；现有 `sessionTokenStats.context` 与 `estimateContextTokens()` 均不适合作为指示器来源。
