# 006 任务目录独立与归档按需读取

状态：verified。
批准依据：2026-09-20 用户明确要求将 tasks/ 从 docs/ 独立，并归档已完成任务，调用 Harness 时不被动阅读它们。

## 修改与影响

根目录 tasks/ 与 docs/ 并列；active 保存未完成任务，archive 保存已完成或取消任务。默认发现只读取 active 的标题/状态，选定后读正文。归档内容只有明确指向的历史需求才可读；无活跃匹配不自动回退。

同步 AGENTS、项目 skills、操作/设计/记录文档、链接和忽略规则；.ignore 默认隔离归档搜索，Git 仍跟踪归档。task_state 默认排除归档正文及差异；review 默认把任务树排除在泛快照/补丁外，仅绑定明确选择的任务/规范记录，使用 --include-archive 才能选择归档文件。显式指定时也不顺带加载全部附件。

本次仅迁移 9 个 done 任务；1 个仍为 blocked 的旧 Harness 验证任务留在 active，不推断它已经完成。原始报告、证据及旧检查点逐字节保留。不会改变 App 行为、提交或推送代码。

## 验证与撤销

检查迁移数量、完整性、维护中文档链接、默认读取与显式选择行为、旧快照验证、Harness 单元测试及 diff。回退可依据任务内迁移映射移动原位置并还原入口改动，不能覆盖期间新增工作。证据存放于本次任务，不修改历史审查报告。
