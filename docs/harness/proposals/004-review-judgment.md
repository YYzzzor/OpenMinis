# 提案 004：审查意见与验收判断分离

状态：implemented
日期：2026-09-11

## 原因与审批

跨模型审查可能误报、错判严重程度或提出不必要的扩展。用户明确批准：“可以调整 Harness 框架，说明 Pi 的结论需要核实，而不是直接决定验收。”本提案记录该授权及实施范围，不需要再次请求同项批准。

## 修改与影响

AGENTS.md、设计、操作说明、记录格式及 review-task skill 明确：Pi 提供待核实意见；主 Agent 依据已确认意图、代码与验证判断采纳与否，并独立记录验收判断。blocking/no_findings 均不自动决定验收。不采纳必须给出依据，实质疑点保持开放，目标或范围取舍交给用户。

适用于后续 Pi 审查处理，不绑定具体模型版本。不改变独立审查的适用任务、原始报告保留要求或既有验收标准，不新增模型调用与脚本机制。

## 验证与撤销

检查入口、skill、设计及记录约定一致，执行文档差异检查与 skill 格式校验。用已发生的 N1 部分采纳、N2 复现后采纳作为语义对照；这不是新的独立行为评测。后续试用观察是否出现无依据驳回或盲从意见；如需调整共享规则，另列证据与变更计划供用户审核。
