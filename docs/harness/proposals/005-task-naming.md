# 提案 005：任务命名

状态：implemented
日期：2026-09-11

## 审批与原因

用户明确指定任务命名规则为 “YY-mm-dd Name”，授权本次实施。统一任务定位与文件浏览中的名称。

## 实施范围

任务标题、单文件记录名或任务目录名使用创建日期加名称；目录内 task.md 和附件不重复日期。更新、归档保留原名。同步 AGENTS.md、设计、记录格式、命令示例及当前任务目录，保留历史审查快照原名与内容。

本提案不新增归档自动化。既有设计已约定 docs/tasks/archive/ 保存完成或取消任务；当前 Harness 尚未整体验收，不执行归档。

## 验证

检查路径与引用、含空格参数的 inspect/checkpoint 行为及文档差异。命名与文档变更不重复执行脚本测试，不代表归档流程已经完成端到端验证。
