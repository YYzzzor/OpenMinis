## 更新规则

维护者告知已推送 TestFlight（或已安装使用）后，Agent 更新本文：

1. **核对事实**：读最新归档的 `Info.plist`（版本、构建号、上传事件与时间、分发记录 ID）和各产品的 `Info.plist`；对照 `git log` 确认源码分支、HEAD 与未提交改动；必要时在归档二进制中搜索新功能的字符串，确认包含对应代码。
2. **更新“当前状态”**：最新上传、下一次可用 Build 号。只有维护者明确确认后，才改“已确认安装使用”。
3. **新增一条发布记录**，放在最上面：新增内容只写相对上一 Build 的产品变化，链接任务记录；不面向用户的改动单独列一行。
4. **更新“待确认事项”**：加入新的待确认项，删去已确认或已失效的项。
5. 本文只记录事实，不复述过程。不读 App Store Connect 后台时，不写后台处理状态。
