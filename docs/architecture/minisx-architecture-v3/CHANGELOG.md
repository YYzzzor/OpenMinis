# 阅读版 v3 变更

沿用第二版清晰的模块层级与流程导航，本次聚焦 iSH、原生桥接、系统框架和原生能力边界。

## 三个模块

- iSH 增加命令接收、会话文件上下文、独立 shell、输出回调、超时停止和 toolResult 返回链路。
- 原生桥接增加注册、处理器分发、参数解析、系统授权、对象查询与 JSON 返回，以日历查询贯穿。
- iOS 框架增加 API 与项目封装的对应关系，以及授权、对象范围、运行条件与结果验证。
- 保留全局位置缩略图；三个模块分别高亮，并提供跨模块阅读和返回原步骤入口。

## 独立能力清单

- 依据固定提交的注册入口列出 27 组处理器，按 4 个阅读类别分组。
- 每项列明命令、常用操作、缺口、条件、核查深度和固定提交源码位置。
- 集中展示 11 类重点缺口、范围限制与待核验事项，支持分类、关键词搜索、条目深链接和键盘展开。
- 文件、记忆、图片和 MCP 等相关工具单独说明接入路径。
- 框架对应表链接到具体能力条目。

## 文件与检查

- 7 个 HTML 入口全部自包含；共享一份源数据及生成源码。
- 增加可复用的页面回归检查脚本，记录 135 项实际检查。
- 检查了 360–1440 像素视口，修正窄屏长路径和符号溢出。
- 使用固定提交的静态代码与文档作为依据；实机执行、系统授权与 Safari 验证仍待进行。
- GitHub 仓库保持原样。
