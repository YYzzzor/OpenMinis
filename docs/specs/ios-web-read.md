# MinisX iOS 统一网页读取

`web_read` 读取公开网页，并向模型说明正文、来源、读取范围和限制。

## 名称与含义

| 名称 | 含义 |
| --- | --- |
| 匿名读取 | 读取工具不继承既有浏览器的登录身份。 |
| 正文编号 | 一份已保存的固定正文的标识；模型凭编号继续读取。 |
| 当前用户请求 | 从用户发送消息到 Agent 完成此次回答的过程。 |
| 工具批次 | 模型在一次响应中提出的一组工具调用。 |
| WebContent | WebKit 用来执行网页的独立进程。 |

## 当前任务不实施的能力

PDF 页内文字提取和 OCR 留待后续独立任务评估。
OCR 包括扫描件及图片中的文字识别。
本任务按 F3 返回 PDF 资源信息及未读取状态。

## 职责

- **W1 [拟议]** `web_read` 第一版以匿名身份读取公开 HTTP/HTTPS 网址。
  - 工具直接提取 HTML、纯文本和 Markdown。
  - PDF、图片和访问限制按照 F3 处理。
- **W2 [拟议]** `web_read` 在一次调用内完成获取、提取和有次数限制的回退。
  - 输入包含网址及可选读取目标。
  - 各阶段不额外调用模型。
- **W3 [拟议]** `web_read` 报告读取事实，模型判断证据能否支持回答。
  - 工具向模型说明可读正文及影响回答的读取限制。
  - 工具将详细阶段耗时、资源计数与内部请求时序保留在诊断中。
  - 模型决定是否补充来源，并解释内容冲突。
  - 模型对收费、认证和许可结论引用能够直接支持该结论的已读来源，依据不足时说明未确认。
  - 模型在最终回答中保留来源的适用条件，区分直接事实、推断和未确认事项，标题及建议采用相同的证据标准。
  - 未发现条款只支持“尚未确认”；模型对缺乏依据的收费或许可结论在读取相关官方页面后最多针对性补充两次，仍无直接依据时说明未确认并结束回答。
  - 工具取得正文与 Agent 完成查询分别判定。
- **W4 [生效]** 模型使用`web_search`发现公开来源，并用`browser_use`完成网页交互。
  - 网页交互包括点击、输入和复杂操作。
  - `web_read` 内部渲染只加载目标页面并执行固定提取程序。
  - 工具遇到登录或用户操作要求时报告限制。
- **W5 [生效]** 工具说明和系统提示共同引导模型依据读取目的选择工具。

  | 场景 | 模型的动作 |
  | --- | --- |
  | 已知公开网址（含可访问的回环地址） | 优先使用 `web_read`；只为明确的信息缺口或资源交接使用其他读取方式。 |
  | 公开关键词检索 | 优先使用`web_search`。 |
  | 搜索页面交互或匿名搜索明确失败 | 使用`browser_use`；失败后的搜索按Google/Bing既有策略执行。 |
  | 当前用户请求已有适用且足够的证据 | 直接用于回答。 |
  | 存在明确缺口或更新要求 | 针对目标补充读取。 |

- **W6 [拟议]** 模型用受既有许可约束的 `browser_use` 读取登录或交互相关内容。
  - 工具在对应标签中读取既有登录身份或交互后的页面。
  - `web_read` 保持匿名，并说明匿名身份遇到的限制。
  - 两种工具的结果分别保留来源和身份范围。

## 内容与来源

- **C1 [拟议]** `web_read` 用小型 JSON 向模型提交正文、来源、读取状态和已知限制。
  - 必填字段为 `url`、`title`、`retrieved_at`、`read_status`、`content` 和 `limitations`。
  - `content` 保留 Markdown；状态只说明读取事实，不宣称回答完整。
  - 来源替换时说明请求网址及备用正文的关系。
  - 已保存正文提供 `document_id`；片段读取提供实际范围和可用续读位置。
  - 未读取资源提供地址、类型和未读取状态。
  - 详细阶段耗时、资源计数与内部请求时序保存在有上限且脱敏的诊断中。
  - 字段类型、条件和示例见[结果契约](../../tasks/active/26-10-02%20Agent%20网页查询效率优化/validation/result-contract.md)。

- **C2 [拟议]** 正文提取保留结构，并报告可能缺失内容的迹象。
  - 工具保留标题和段落。
  - 工具保留链接和代码。
  - 工具保留必要表格的行列关系，包括合并单元格对应的表头和类别；解析受限时说明缺口。
  - 工具说明误选导航栏或页脚、未加载区域及相关图片。
  - 这些迹象不能证明证据已经充分。
- **C3 [拟议]** 应用在读取和输出的各阶段分别说明实际长度和截断范围。
  - 诊断记录下载、正文提取、工具格式化和最终模型输入的长度与截断。
  - 模型结果保留实际返回范围及影响判断的缺口。
  - 应用先限制正文再编码 JSON；最终 Provider 结果可解析，提示写入对象内。
  - 达到响应上限或只取得部分文档时，工具说明尚未取得的范围。
  - 工具只承诺继续读取实际保存的正文。
- **C4 [拟议]** `web_read` 通过定位和正文编号返回长文中的目标内容。
  - 模型可以提交标题、代码标识符或明确关键词。
  - 工具返回正文编号及继续读取的位置，并限制续读量。
  - 同一编号对应固定正文，续读不重新下载网页。
  - 工具分别报告“已覆盖范围内未命中”和“目标范围尚未取得”。

## 路线与特殊资源

- **F1 [拟议]** 自动读取路线依次检查主文档、公开备用正文和匿名渲染。
  1. 工具先获取主文档。
  2. 主文档不足时，工具检查页面明确声明的公开正文格式或已有提取方法的内嵌数据。
  3. 内容仍不足时，工具使用匿名 WebKit 渲染。
  4. 应用将候选来源、重定向和全部尝试计入统一预算。
- **F2 [拟议]** `web_read` 说明正文不足的情况，并允许模型明确请求补充。
  - 工具报告空壳页面、加载提示和局部提取不足；局部正文仍有加载占位符时，工具补充读取或报告部分完成。
  - 模型发现缺口后，可以选择已有正文续读或动态渲染。
  - 重复请求遵守下载次数和回退次数上限。
- **F3 [拟议]** `web_read` 对尚未读取的资源或受限内容返回准确的交接信息。

  | 情况 | 工具返回什么 |
  | --- | --- |
  | PDF、图片或其他未支持格式 | 可定位资源信息、未读取范围和能力限制。 |
  | 需要认证 | 来源及认证要求。 |
  | 访问被拒绝 | 来源及拒绝原因。 |
  | 下载成功、内容读取尚未执行 | 已取得字节的事实，以及内容尚未读取的状态。 |

  对应内容查询在实际读取完成前保持未完成。

## 身份与复用

- **I1 [拟议]** 原生 HTTP 使用独立匿名会话，并隔离共享浏览器凭据。
  - 会话不读取共享 Cookie、认证存储或共享响应缓存。
  - 应用不将共享凭据导出到模型、shell、脚本或普通文件。
- **I2 [拟议]** 内部 WebKit 使用独立匿名网站存储，并保留既有浏览器登录。
  - 渲染器不使用共享默认存储或 Cookie 备份恢复。
  - 渲染器的创建、取消及释放不清除既有登录。
- **I3 [拟议]** 正文编号只在原聊天、当前用户请求和原读取身份中有效。
  - 身份改变或作用域结束后，旧编号失效。
  - 日志、错误和诊断不包含 Cookie、Authorization 或网址中的敏感凭据。
- **I4 [拟议]** `web_read` 独立管理页面状态，并保留原浏览器的用户操作流程。
  - 渲染器独立持有导航、DOM、UA、viewport 和观察器。
  - 创建、读取及清理不修改既有标签和用户操作状态。
  - 浏览器接管的暂停及恢复继续由原会话流程管理。

## 时间与资源

- **R1 [拟议]** 应用从调用进入排队时计算统一截止时间和尝试预算。
  - HTTP、重定向、备用请求、渲染和提取共用该预算。
  - 应用恢复前台时先核对已经流逝的时间。
  - 数值通过代表性 iOS 实验确定，并保存为可检查的配置。
- **R2 [拟议]** 应用实际停止结束范围内的工作，并丢弃迟到内容。
  - Stop、超时、会话删除和异常均取消请求并解除等待。
  - 应用停止或释放临时渲染，并按状态清理部分文件和缓存。
  - 结束后的回调不再启动回退或提交内容。
- **R3 [拟议]** 应用为读取资源设置明确上限和清理条件。
  - 应用限制响应字节、正文大小和缓存条目。
  - 应用限制并发队列和诊断记录。
  - 解析不阻塞主线程。
  - 正文就绪检查使用有界事件监听或低频采样。
- **R4 [拟议]** 工具取得正文后，应用停止不再需要的加载和观察。
  - 文字读取只提取对应内容。
  - 截图或图像处理只在读取目标需要时执行。
- **R5 [拟议]** 应用共同统计跨聊天的浏览器及匿名渲染资源。
  - App 级预算记录每个实例所属的聊天和调用。
  - 槽位不足时，读取有时限地排队或报告资源限制。
  - 读取准入不抢占活动或接管中的浏览器。
  - 资源压力处置优先清理可释放的临时读取资源。
- **R6 [生效]** 应用按照触发范围结束工具工作。

  | 触发 | 清理范围 |
  | --- | --- |
  | 单次读取超时或内部取消 | 对应调用。 |
  | 工具气泡 Stop | 当前批次中的`web_read`、`web_search`、`browser_use`及其队列项。 |
  | 会话 Stop | 当前会话活动任务中的这三种工具及其队列项。 |

  其他聊天任务、既有登录和已提交结果按照原生命周期保留。

## 接入与验收

- **A1 [拟议]** 应用在 Agent 全流程中一致接入 `web_read`，并保留原调用标识。
  - 接入包含工具定义、派发和系统提示。
  - 接入包含许可、副作用说明和 Stop。
  - 接入包含消息展示和持久化。
  - 正常查询优先用它读取已知公开网址。
- **A2 [拟议]** 测试分别记录测试输入、iOS 工具和完整 Agent 查询的结果。
  - 确定性变体由产品测试组逐项验证，证据对应案例编号。
  - 完整查询选取代表场景，使用正常生产提示和全部可用工具。
  - 测试在相同模型和配置下多次比较。
  - 比较内容包括回答依据、完整性及失败结果。
  - 比较指标包括总耗时、模型请求次数和工具调用次数。
- **A3 [拟议]** 测试通过正确性、隔离、取消和预算验收后，再判断性能收益。
  - 测量记录设备、构建和网络。
  - 测量记录冷暖缓存及前后台条件。
  - App 与 WebContent 的资源表现分别观察。
  - 未测量的真机内存、能耗及锁屏表现保留未验证状态。
- **A4 [拟议]** 测试使用真实 Agent 和产品并行路径验证两种工具共存。
  - 正常提示验证工具选择及证据复用。
  - 产品并行路径验证标签状态、共同资源边界和取消范围。
  - 完成、超时和取消结果在界面、模型历史及数据库中对应同一调用。

## 验收场景

| 场景 | 预期结果 | 规则 |
| --- | --- | --- |
| 正文先于装饰资源就绪 | 工具返回当前目标文档，并结束无用等待。 | C1、C2、F2、R1、R4。 |
| 局部正文稍后出现 | 工具说明缺失范围，模型可以明确要求渲染。 | C1、C2、F2。 |
| 长文中部或尾部含跨标签标识符 | 工具保留标识符及表格关系；模型能够取得目标片段。 | C2–C4。 |
| PDF、图片及访问限制 | 工具准确识别资源及未读取范围，并提供可定位交接信息。 | F3、R1–R3。 |
| 既有浏览器预先登录 | 匿名 HTTP 和 WebKit 均无法取得私人标记，既有登录保留。 | I1–I3。 |
| 各阶段停止或锁屏后恢复 | 实际工作结束，迟到内容丢弃，恢复后核对剩余时间。 | R1–R3。 |
| 公开、登录或交互页面查询 | 模型依据目标及身份选择工具，并复用已有充分证据。 | W5–W6、A4。 |
| 用户接管时读取 | 读取不修改原标签，也不提前解除接管。 | I4、A4。 |
| 两种工具跨聊天占满预算 | 总实例计数一致，读取排队有时限。 | R5、A4。 |
| 超时、Stop、乱序完成及重载 | 清理范围准确，界面、模型历史及数据库的结果配对一致。 | R6、A4。 |
| 正常 Agent 查询官方说明或价格 | 回答依据充分；文字、图片及协议问题分别判定。 | W3、A1–A3。 |
