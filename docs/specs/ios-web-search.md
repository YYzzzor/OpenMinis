# MinisX iOS 匿名网页搜索

`web_search` 用关键词发现公开来源，`web_read` 阅读选定来源的正文。

相关规范：[浏览器自动化](ios-browser-automation.md)、[统一网页读取](ios-web-read.md)、[Agent生命周期](ios-agent-run-lifecycle.md)、[资源规范](resource-efficiency.md)。

## 入口与范围

第一版使用DuckDuckGo Lite公开文字页面，不要求搜索账户或API密钥。
工具取得当前结果页，保留来源及后续结果入口，明确已经覆盖的范围。
浏览器交互、用户接管和登录页面继续使用`browser_use`。

## 规则

- **S0 [生效]** 应用先保留当前结果页的有效信息，再优化搜索耗时。
  - 工具保留有效条目的标题、摘要和来源链接。
  - 单次输出限制通过保存结果和续读处理。
  - 实际下载或提取缺失在结果中明确报告。
  - 搜索结果只用于发现来源，模型阅读来源后判断事实与语义相关性。
- **S1 [生效]** 工具等待本次HTTP正文取得完成，并核对结果结构后提交内容。
  - 匿名渲染回退核对本次文档和结果区域。
  - 第一条标题、非空文字及HTTP成功均不足以单独判定搜索有效。
- **S2 [生效]** `web_search`一次返回查询、引擎、状态和可直接使用的结果内容。
  - 内容包含标题、完整来源网址及可取得的摘要。
  - 超出单次输出预算时，结果提供固定正文编号、已返回范围及续读位置。
  - 续读只在原会话、当前用户请求和匿名身份中有效。
  - 后续页入口和未覆盖范围保持可观察。
- **S3 [生效]** 有效HTTP搜索直接返回文字，不创建WebView或等待截图预览。
  - 普通`browser_use`动作继续遵守原行为。
  - 渲染回退在取得当前结果后结束无关加载，不生成预览截图。
- **S4 [生效]** 工具区分有效结果、明确无结果、验证要求和提取失败。
  - 空壳、验证码和缺少来源链接的页面保留准确限制。
  - 明确无结果直接返回；模型可以调整查询。
  - 取得部分条目时保留内容，并说明缺口。
- **S5 [拟议]** HTTP与渲染回退均隔离既有浏览器的登录身份。
  - HTTP使用独立临时会话，不读取共享Cookie、认证存储或响应缓存。
  - 渲染使用匿名网站存储，不恢复浏览器Cookie备份。
  - 创建、读取和清理保留既有标签、登录及用户接管状态。
  - 诊断和模型结果排除Cookie、Authorization及敏感凭据。
- **S6 [生效]** 每项搜索从进入队列起共用一个截止时间及有界资源预算。
  - 下载字节、保存内容、排队、并发、尝试及诊断均有明确上限。
  - 解析在主线程之外执行。
  - 单次取消只结束对应调用，批次Stop结束该批，会话Stop或删除结束该会话。
  - 取消后不启动回退，迟到结果丢弃。
  - 作用域结束或资源压力时释放对应缓存和匿名渲染。
  - 单项取消或超时清理本次新建缓存；续读借用的共享归档保留至原作用域、TTL或预算清理，避免破坏其他续读。
- **S7 [拟议]** 测试先核对有效信息与来源，再评价性能收益。
  - 同一引擎分别比较HTTP和浏览器读取方式。
  - 不同引擎分别记录质量、失败状态和耗时。
  - 完整Agent测试使用正常工具集合，记录工具批次及原调用标识。
  - 未测量的真机内存、能耗和锁屏表现保持未验证。
- **S8 [生效]** 资源允许时，应用并发执行两个独立搜索，并分别配对结果。
  - 活动搜索最多两项，其他调用有界等待。
  - 每项搜索内部回退顺序执行，并保留原并发槽位。
  - 一项完成、回退或取消不导致另一项丢失。
  - 匿名渲染遵守已有共享实例预算，不抢占用户接管中的页面。
- **S9 [生效]** HTTP读取失败或结果结构不足时，工具最多执行一次同引擎匿名渲染回退。
  - 第一版从Lite HTTP读取回退到DuckDuckGo HTML页面渲染。
  - 两个读取入口共享原截止时间，重定向也受上限约束。
  - 回退仍失败时返回已取得内容及准确限制，不宣称查询完整。
  - 模型可以在收到明确失败后使用`browser_use`，按Google及Bing既有策略补充检索。
  - 工具内部回退不调用模型，也不暗中更换查询。

S5和S7仍为部分验收；实测范围与限制见[验证记录](../../tasks/active/26-10-02%20BrowserUse%20搜索速度优化/verification.md)。

## 验收场景

| 场景 | 预期结果 | 规则 |
| --- | --- | --- |
| 当前页包含多个结果及尾部重要条目 | 标题、摘要、来源及尾部条目保留。 | S0–S2 |
| 输出超过单次预算 | 编号续读取得保存内容，不重新搜索。 | S0、S2 |
| HTTP直接取得有效结果 | 没有WebView、截图或额外取链接调用。 | S1–S3 |
| 验证码、空壳或明确无结果 | 状态准确，回退次数及范围可追溯。 | S4、S9 |
| 浏览器已有登录及用户接管 | 匿名读取无法取得私人标记，原状态保持。 | S5 |
| 两项搜索并发，一项取消或回退 | 结果独立，另项继续，预算计数准确。 | S6、S8 |
| 排队、截止时间、批次及会话停止 | 对应范围释放，没有迟到结果或重启回退。 | S6 |
| Jev与Cloudflare Clef原问句 | 两个主题的来源可用；质量通过后比较整轮耗时。 | S0、S7–S8 |
