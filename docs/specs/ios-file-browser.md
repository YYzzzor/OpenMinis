# MinisX iOS 文件浏览器

导航：[Spec 索引](index.md)。

范围：`FileBrowserView` 在各入口中的导航与关闭行为，以及文件夹页的目录读取。资源开销的通用要求见 [资源规范](resource-efficiency.md)。

## 定义

| 名称 | 含义 |
| --- | --- |
| 文件夹页 | 显示一个目录内容的页面 |
| 根目录 | 入口指定的最高目录，文件浏览器不显示它以上的内容 |
| 第一页 | 入口打开时显示的文件夹页 |
| sheet 入口 | 用 sheet 呈现、自带 `NavigationStack` 的入口 |

## 入口

| 入口 | 呈现方式 | 根目录 | 第一页 |
| --- | --- | --- | --- |
| 设置 → 存储 → 会话 → Browse Files | 推入"设置"导航栈 | 会话目录 `Library/MinisChat/minis/<会话ID>` | 根目录 |
| 对话 `⋯` → 浏览对话文件；空对话的浏览按钮 | sheet | `/` | `/var/minis` |
| 下载面板 → 在文件中显示 | sheet | `/var/minis/workspace` | 根目录，并高亮下载的文件 |
| 终端 | sheet | rootfs 根目录 | 根目录 |
| Rootfs 管理 | sheet | `/` | 根目录 |
| 挂载详情 | sheet | 挂载的外部文件夹 | 根目录 |

## 导航

- **F1** 用户点文件夹行时，App 推入一个新的文件夹页显示该文件夹。用户点 `<` 或从左边缘右滑时，App 弹出当前文件夹页，回到上一层。
- **F2** 文件夹页的目录等于根目录时，标题为 "Files"；否则标题为该目录的名字。
- **F3** 路径栏显示从根目录标签到当前目录的完整路径，只用于显示，点击没有效果。
- **F4** 推入的文件夹页的 `⋯` 菜单不显示 Go to Parent Folder。

## 第一页与关闭

- **F5** 第一页的目录不是根目录时，`⋯` 菜单显示 Go to Parent Folder。用户点它时，第一页就地切换到上一级目录，不推入新页面。读取新目录期间显示加载指示器，不显示上一个目录的列表。
- **F6** 第 2 层及以后的文件夹页，在左上角 `<` 的右侧显示 Close。用户点它时，App 一次退出文件浏览器，不逐层返回。
- **F7** 第一页的退出方式按入口区分：sheet 入口的第一页在左上角显示 Close；"存储"入口的第一页只显示 `<`。

"退出文件浏览器"的结果按入口区分：

| 入口 | 退出后 |
| --- | --- |
| sheet 入口 | sheet 关闭 |
| "存储"入口 | 所有文件夹页一次弹出，回到会话存储页 |

## 数据与资源

- **F8** 文件夹页只在用户点击文件夹后创建。列表行不预先创建目标页面。
- **F9** 文件夹页第一次显示时只读取一次目录，读取前已应用排序和"显示隐藏文件"设置。读取在后台线程进行。
- **F10** 用户返回到已经显示过的文件夹页时，页面先显示上次的列表，不显示加载指示器；同时在后台重新读取一次目录，完成后替换列表。文件夹页被弹出时，它的 `FileBrowserViewModel` 随页面释放。

排序和"显示隐藏文件"的设置保存在 `@AppStorage`，所有文件夹页共享。预览、导出、导入、删除、移动和复制在当前文件夹页上进行，完成后只重新读取当前页的目录。

## 不在范围内

- "移动到… / 复制到…"使用的 `DirectoryPickerView`，它在 sheet 内就地切换目录。
- 各入口的呈现方式和根目录。

## 验收场景

| 场景 | 预期 | 规则 |
| --- | --- | --- |
| "存储"入口点 `attachments`，再点 `<` | 先推入标题为 "attachments" 的页面；点 `<` 回到标题为 "Files" 的会话目录页 | F1、F2 |
| 在子文件夹页从左边缘右滑 | 回到上一层文件夹页 | F1 |
| 点路径栏中的任一段 | 页面不变 | F3 |
| sheet 入口进入第 2 层 | 左上角是 `<` 和 Close；`⋯` 菜单没有 Go to Parent Folder | F4、F6 |
| sheet 入口第 3 层点 Close | sheet 关闭 | F6 |
| "存储"入口第 3 层点 Close | 回到会话存储页 | F6 |
| 打开"浏览对话文件"后点 Go to Parent Folder | 第一页就地切换到 `/var` | F5 |
| 在子文件夹页移动文件到上一级后返回 | 上一级页面立即显示上次的列表，随后出现被移动的文件 | F10 |
